## Description / 概要 (最大4000文字)
```
カンパイ！は、スマホ1台をみんなで回して遊べる、日本語のパーティーゲーム集です。友だちとの集まり、家族のだんらん、旅行の夜、イベントの余興に。アプリを開いてすぐスタートでき、通信もログインも不要です。

■ オリジナルの会話ゲーム
・意思疎通：こっそり配られた1〜100の数字を、お題に沿った言葉で表現。みんなで相談して小さい順に並べ、ぴったり並べば全員成功
・英語禁止：カタカナ語のお題を、カタカナと英語を使わず日本語だけで説明。当てた人と出題者の両方に得点
・匿名アンケート：「誰が一番◯◯？」をスマホを回してこっそり投票し、結果を発表

■ みんなで作るお題
山手線ゲームのお題は、自分で追加したり、みんなが投稿したお題に投票したりできます。不適切なお題は通報・ブロックできるので安心です。

■ 定番ゲームもひとつに
・山手線ゲーム：お題に沿って、テンポよく順番に答える
・キングカード：カードを引いて、出た数字のルールが発動
・ハイ＆ロー：次のカードは上か下か
・ロシアンルーレット：スマホを回して、爆発するのは誰だ
・チンチロ：サイコロ3つで役を競う

■ 自分たちだけの罰ゲーム
罰ゲームはみんなで自由に作成・保存できます。プレイヤーを登録すれば、負けた回数も自動で記録。

■ 正直な価格
基本無料。広告を消したい方だけ、買い切りの「広告非表示」（¥300）をどうぞ。月額・年額のサブスクリプションは一切ありません。
```

## App Review notes (App Review Information → Notes)
```
This build is a general party-game app for groups sharing one iPhone. It contains no drinking
mechanics, no alcohol references, and no age gate. Losers do a group-chosen 罰ゲーム (light dare)
that players write themselves in Settings.

User-generated content: in 山手線ゲーム → 「お題を追加・みんなのお題」, users can share topics.
Posting rules are accepted before the first share, an NG-word filter blocks abusive text, and
every shared topic has a "…" button to report it or block its author (both hide it immediately).
Reports are reviewed within 24 hours. Contact: taigamura.dev@gmail.com
```
