## Description / 概要 (最大4000文字)
```
カンパイ！は、飲み会・宅飲み・合コンで今すぐ盛り上がれる、日本語のパーティーゲーム集です。アプリを開いてすぐスタート。通信もログインも不要で、スマホ1台をみんなで回して遊べます。

■ 8つのゲームを収録
・山手線ゲーム：お題に沿って、テンポよく順番に答える定番
・ロシアンルーレット：スマホを回して、爆発するのは誰だ
・ハイ＆ロー：次のカードは上か下か
・チンチロ：サイコロ3つで勝負
・キングスカップ：カードごとにルールが発動
・匿名アンケート：「誰が一番◯◯？」をこっそり投票して結果を発表
・英語禁止（新登場）：カタカナ語を、カタカナと英語を使わず日本語だけで説明して当ててもらう
・意思疎通（新登場）：こっそり配られた数字を言葉で表現し、みんなで小さい順に並べる

■ 準備いらず、すぐ乾杯
面倒な設定は不要。開いてタップすればすぐ始められます。プレイヤーの名前を登録すれば、負けた回数も自動で記録。オリジナルの罰ゲームも自由に追加できます。

■ 安心して遊べる設計
飲む・飲まないは常に自由です。負けても罰ゲームを選べるので、お酒が飲めない人も一緒に楽しめます。一気飲みをあおる演出は一切ありません。初回に20歳以上の確認があります。

■ 正直な価格
基本無料。広告を消したい方だけ、買い切りの「広告非表示」（¥300）をどうぞ。月額・年額のサブスクリプションは一切ありません。

飲みすぎには注意して、体調と相談しながら適量を楽しみましょう。
```
