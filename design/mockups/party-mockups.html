カンパイ！ をパーティーに寄せる

Current build reads a touch like a productivity app: even frosted-glass tiles, thin restrained type, one quiet accent. This exploration keeps the locked 生ビール palette and fonts, but turns the volume up: huge type, per-game color, chunky bordered tiles, loud reveals. Everything below is a target for the code (the type scale was already bumped one notch this session).

01

Type that shouts

Titles & お題 go 17–34px → 28–44px+. Readable across a table.

02

Color per game

One frosted glass for all → a signature color per tile. Instant recognition.

03

Chunky & tactile

Solid tiles, 2px ink borders + hard drop-shadow. Toy-like, pressable.

04

Loud loser

A loss floods the screen red with a rotated 罰ゲーム card. The payoff moment.

05

Playful tilt

Badges & cards sit at a slight rotation. Nothing is on a rigid grid.

06

One calm popup

All modals settle with the quiet PopIn (no bounce) — consistency = polish.

Aホーム — the party lineup

Each game gets a colored icon chip + Dela Gothic title on a solid, ink-bordered card with a hard shadow, so the home screen reads as a bright game shelf, not a settings list. A tilted 「6つのゲーム」 badge and per-game tags (定番・盛り上がる) add party energy on first glance.

Bゲーム画面 — お題 as the star

The お題 becomes a 44px Dela Gothic headline on a tilted ink-bordered card — the single biggest thing on screen. Buttons are full-width, chunky, colored. ヒント examples are pills. This is the fix for “text too small on game screens”: the answer word dominates.
