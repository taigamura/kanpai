ビアグラス UI

Six ways to make the whole app read like the inside of a beer glass: an amber liquid ground, a foam head across the top, carbonation rising, and the game tiles floating as frosted-glass panels. Each is a different kind of beer + glass, not a recolor. Shown on the Home screen. Keeps the カンパイ！ type (Dela Gothic One) and vector icons.

Pick one (or mix: e.g. "c1's foam + c3's rim"). Chosen direction gets built as the real theme, likely with the beer-fill as a live progress/atmosphere layer rather than static.

How this would work in the app: the amber gradient + foam become the screen background token, so every screen (home, games, results) sits "inside the glass." The foam head can double as the safe-area/header band; carbonation can idle subtly and fizz up on a win or a 罰ゲーム reveal. Trade-offs to weigh: dark text on amber (c1–c5) is warm and legible but departs from the current cream-on-navy; the stout (c6) keeps light-on-dark like today but flips the mood premium/moody. Frosted tiles need a `backdrop-filter` fallback on older devices (already included). Tell me which to push.
